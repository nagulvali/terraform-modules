# Agent instructions

Before working in this repository, read and follow:

1. `.ai/instructions.md`
2. `.ai/architecture.md`
3. Relevant files under `.ai/conventions/`
4. Relevant workflows under `.ai/skills/`

The `.ai/` directory is the shared source of truth for Copilot, Codex, and
Cursor. Keep cross-agent guidance there rather than duplicating it in this
adapter.
